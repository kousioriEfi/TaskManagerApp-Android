# 📱 Task Manager App (Android)

A simple Android app for managing personal tasks, built with **Kotlin**.
Developed for the course *Mobile Application Development* at Harokopio University of Athens.

## ✨ Features
- Add tasks with name, description, start time, duration, difficulty (0–10) and optional location
- Input validation with clear error messages
- List of upcoming (not completed) tasks, sorted by start time
- Local data storage that persists between app launches

## 🛠️ Tech Stack
- **Kotlin**
- **Room** (SQLite) for local database, with entities, DAOs and foreign keys
- **Coroutines** for running database operations in the background
- **RecyclerView** for displaying the task list
- **Gradle (Kotlin DSL)**

## 🚀 How to Run
1. Clone the repository
2. Open the project in **Android Studio**
3. Let Gradle sync
4. Run on an emulator or a physical Android device
